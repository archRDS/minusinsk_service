# carservice124 — сайт для GitHub Pages

Отдельная копия шаблона для шиномонтажной мастерской и СТО carservice124 в Минусинске. Исходный шаблон остаётся в соседней папке `shinomontazh-template`.

## Публикация на GitHub Pages

Эта папка — готовый корень отдельного репозитория. В репозиторий нужно добавить её содержимое, включая скрытую папку `.github`; папку `carservice124-minusinsk` целиком внутрь репозитория помещать не нужно. Сайт находится в `dist`, сборка и зависимости не требуются.

1. Создайте на GitHub репозиторий для сайта и загрузите в его корень содержимое этой папки.
2. В настройках репозитория откройте **Settings → Pages** и выберите **Source: GitHub Actions**.
3. Отправьте изменения в основную ветку репозитория. Процесс **Publish carservice124 to GitHub Pages** опубликует содержимое `dist`. Его также можно запустить вручную на основной ветке через вкладку **Actions**.

Локальный репозиторий уже создан, его основная ветка — `main`, сайт сохранён первым коммитом. После создания пустого репозитория на GitHub выполните из этой папки (подставьте адрес своего репозитория):

```powershell
git remote add origin https://github.com/USERNAME/REPOSITORY.git
git push -u origin main
```

После успешной публикации ссылка появится в **Settings → Pages** и в завершённом процессе **Actions**. Для обычного репозитория она имеет вид `https://ИМЯ-ПОЛЬЗОВАТЕЛЯ.github.io/ИМЯ-РЕПОЗИТОРИЯ/`. Пути к файлам в сайте относительные, поэтому он работает и по такому адресу.

`server.mjs` и `preview.png` нужны только локально: процесс публикации отправляет на GitHub Pages только `dist`.

## Запуск

Откройте PowerShell в этой папке и выполните:

```powershell
node server.mjs
```

Сайт будет доступен по адресу <http://localhost:4174>. Для остановки сервера нажмите `Ctrl+C`.

## Данные

Название, адрес, телефон, WhatsApp, режим работы, услуги, цены и отзывы находятся в [`dist/config.js`](dist/config.js). Фото первого экрана — `dist/hero-photo.png`.

Данные проверены 20.10.2026 по карточке [carservice124 в 2ГИС](https://2gis.ru/minusinsk/firm/70000001064887213), её разделам [«Цены»](https://2gis.ru/minusinsk/firm/70000001064887213/tab/prices), [«Инфо»](https://2gis.ru/minusinsk/firm/70000001064887213/tab/info) и [«Отзывы»](https://2gis.ru/minusinsk/firm/70000001064887213/tab/reviews). В карточке прайс отмечен как обновлённый 01.12.2025, поэтому стоимость стоит подтвердить у владельца перед передачей сайта клиентам.

Форма открывает подготовленное сообщение в WhatsApp компании. Заявка считается отправленной, только когда посетитель отправит это сообщение сам; время подтверждает мастерская. Сайт не хранит заявки и не резервирует свободные интервалы.

Localhost виден только на вашем компьютере. Для передачи ссылки другим людям понадобится отдельная публикация сайта.
